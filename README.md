# Horizon Drive

An original arcade road racer: beat the checkpoint timer, drift through bends, weave through traffic and pick your route at every fork.

This build contains none of the original game's files. All art, music and sound are generated by the game's own code (see CREDITS.md).

Run it with `cargo run`. Controls: arrows or WASD to drive, Up to accelerate, Down to brake; tap the brake while steering to drift. M switches between automatic and manual gears, E and Q shift, and Esc pauses.
