# Credits

**Original game files used: none.**

No file from the original game's folder was opened, copied or included in this build.
Everything in the game is made by its own code at runtime:

- Road, scenery, cars and on-screen text: drawn with simple shapes (src/render.rs, src/hud.rs).
- The red car is an original drawing of a generic 1990s open-top mid-engine sports car with a rear wing, made from shapes. It has no badges, logos or names of any real car maker.
- Music and sound effects: synthesised in code (src/audio.rs).
- All gameplay numbers are estimates (see MECHANICS.md).
